## Food Delivery Platform 🍔🍕

### Overview
A full-stack food delivery platform that allows users to register, log in, add food items to a cart, and place orders. The frontend is built using React, and the backend is developed using Node.js with Express and MongoDB.

### Features
- **User Registration & Login:** Secure authentication using JWT.
- **Food Detail Page:** Users can view detailed information about food items before adding them to the cart.
- **Filtering Options:** Users can filter food items by category and price.  
- **Add to Cart:** Users can add food items to their cart.
- **Place Orders:** Users can order food with total price calculation and shipping details.
- **Secure & Scalable:** Passwords are hashed, and the system is optimized for performance.

### Tech Stack
- **Frontend:** React, Axios
- **Backend:** Node.js, Express, MongoDB, Mongoose, JWT, bcrypt.js

### Setup
1. Clone the repository:
   ```sh
   git clone https://github.com/Rensi2411/Food-delivery.git
2. Install dependencies
   ```sh
   cd backend && npm install
   cd frontend && npm install

3. Configure .env with database and JWT secret.
4. Start the servers
   ```sh
   npm start (in both frontend & backend)

## API Endpoints

### Auth  
- `/api/user/signup`  
- `/api/user/signin`  

### Add and get Food
- `/api/food/add`
- `/api/food`

### Add and get Cart  
- `/api/user/cart/`  
- `/api/user/cart`  
### Add and get favourite
- `/api/user/favorite/`
- `/api/user/favorite`
  
### Place Order 
- `/api/user/order/`
